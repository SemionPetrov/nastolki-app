# Board Games Collection

Веб-приложение для управления коллекцией настольных игр с HTTPS.

## Технологии
- Python 3.11 + Flask
- Docker & Docker Compose
- Nginx (reverse proxy)
- SQLite
- Let's Encrypt (SSL)

## Требования
- Docker
- Docker Compose
- Доменное имя (например, bbrkv.duckdns.org)
- Сервер с Ubuntu 22.04+
